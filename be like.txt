## TavernRogue 2.0：基于 D&D SRD 的 Roguelike 自走棋制作方案

这份方案将《酒馆战棋》的核心玩法（铸币运营、三连合成、自动战斗）与《杀戮尖塔》式的地图冒险，完全用**D&D SRD 开放的奇幻内容**重新包装。所有名称、种族、怪物和风味均可合法使用，同时保留了构筑与战斗的深度。

---

### 一、游戏概述

**游戏名称**（暂定）：《旅店与巨龙》/ TavernRogue  
**类型**：单人卡牌构筑 + 自动战斗 Roguelike  
**核心体验**：扮演一名奇幻职业者，在旅店招募冒险者组成战队，沿着随机地图讨伐怪物、搜刮宝物，最终击败盘踞在塔顶的远古巨龙。  
**灵感来源**：炉石传说·酒馆战棋（玩法循环）、杀戮尖塔（地图与遗物）、D&D 5e SRD（世界观与生物）。

---

### 二、核心循环

```
进入旅店（招募阶段）
   │ 花费铸币招募冒险者、调整队伍站位
   ├─> 查看地图，选择下一个地点
   ├─> 处理地点事件：
   │    战斗（自动结算）→ 胜利获得铸币、战利品
   │    商店 → 购买特殊冒险者或魔法物品
   │    营地 → 恢复伤势或训练队伍
   │    奇遇 → 文本选择，获得随机增益/减益
   └─> 队伍实力成长，挑战更深的层级
         │
         └─> 击败最终 Boss（远古红龙等）→ 通关
                │ 失败 → 英雄死亡，本局结束
```

---

### 三、英雄与职业

从 D&D SRD 中选取 5 个标志性职业作为初始英雄，每个英雄有一个**被动技能**或**主动能力**（每场战斗可使用一次）。

| 职业 | 技能名称 | 效果 |
|------|----------|------|
| 战士 | 战争咆哮 | 战斗开始时：最左侧的友军获得“守卫（嘲讽）”和 +2 生命值。 |
| 游荡者 | 暗影突袭 | 战斗开始时：对一个随机敌人造成 2 点伤害。 |
| 牧师 | 治疗祷言 | 每场战斗一次：当一个友军死亡时，改为将其移回手牌并恢复全部生命值。 |
| 法师 | 魔法飞弹 | 每场战斗一次：造成 3 点伤害，由所有敌人分摊。 |
| 术士 | 生命分流 | 购买冒险者时，可以消耗 2 点生命值代替 1 枚铸币。 |

英雄初始生命值 30，没有护甲。生命归零则冒险失败。

---

### 四、冒险者（随从）与种族

#### 4.1 种族

采用 SRD 中的六个核心种族，每个种族拥有一个**全局共鸣**（当你场上拥有至少 2/4/6 个该种族随从时触发）。

- **人类**：共鸣——每回合第一次刷新酒馆免费。
- **精灵**：共鸣——你的冒险者获得“敏捷”（有 20% 几率闪避攻击）。
- **矮人**：共鸣——你的冒险者获得“护甲”（受到的伤害 -1，最低为 1）。
- **龙裔**：共鸣——战斗开始时，对随机敌人造成 1/2/3 点火焰伤害。
- **半兽人**：共鸣——你的冒险者攻击时，有 25% 几率造成双倍伤害。
- **提夫林**：共鸣——每当一个友军死亡，随机对一名敌人造成 1/2/3 点暗影伤害。

#### 4.2 关键词（原酒馆机制替换）

- **守卫**（嘲讽）——敌人必须先攻击此随从。
- **力场护盾**（圣盾）——免疫下一次受到的伤害。
- **亡者遗赠**（亡语）——死亡时触发效果。
- **入场技**（战吼）——打出时触发效果。
- **血怒**（复仇）——在一个友方冒险者死亡后触发。
- **连击**（风怒）——每回合可以攻击两次。
- **剧毒**（剧毒）——伤害消灭任何随从。
- **横扫**（狂战斧）——攻击时对目标两侧的敌人造成 1 点伤害。
- **过杀**（超杀）——若造成超额伤害，触发额外效果。

#### 4.3 酒馆等级与招募

- **铸币**：每回合固定获得 3 枚铸币，加上回合基础（随深度递增，最多 10 枚）。未用完清零（或可保留最多 5 枚）。
- **酒馆等级**：随地图层级自动提升（1~6 级），每级解锁更强冒险者。
- **购买**：花费 3 铸币招募一名冒险者。
- **刷新**：花费 1 铸币刷新酒馆内的候选者。
- **三连**：当手牌和场上拥有 3 个相同冒险者时，自动合成“精英版”（属性翻倍，效果强化），并发现一张当前酒馆等级的随机冒险者。

---

### 五、战斗系统

保留回合制自动战斗，但加入少数 D&D 风味调整。

- 双方各有最多 7 名冒险者，从左至右轮流攻击。
- 攻击目标：优先攻击带**守卫**的敌人，否则随机选择。
- 攻击结算：攻击力 - 目标护甲值 = 实际伤害。若目标有**力场护盾**，则抵消该次伤害，护盾消失。
- 关键词触发顺序：使用后进先出事件队列，确保**亡者遗赠**→**血怒**→**召唤**等嵌套正确。
- 英雄在场上所有冒险者阵亡后，会受到敌方幸存者的直接攻击（伤害等于其攻击力）。

---

### 六、地图与节点

地图使用 D&D 地城探险的概念，总共 9 层：

1. 第 1 层：地城入口（营地）  
2. 第 2-7 层：地城通道（随机生成敌人/精英/商店/奇遇/营地）  
3. 第 8 层：远古龙穴（固定 Boss）  
4. 第 9 层（可选）：宝藏密室（若携带特定物品可进入）

每层有 2~4 个节点，节点间有路径连接。玩家只能看到节点类型图标，具体内容进入后才揭晓。

节点类型：

- **怪物巢穴**：普通战斗，掉落铸币和一次“发现”机会。
- **精英守卫**：高难度战斗，胜利后必得一件**魔法物品**（被动宝物）。
- **旅行商人**：可用铸币购买冒险者或魔法物品，也可出售已有冒险者。
- **古老祭坛**（奇遇）：文本事件，选择后获得增益或减益。
- **安全营地**：恢复 30% 生命值，或选择训练一名冒险者（使其永久 +1/+1）。
- **首领**：当前层级的 Boss，击败后提升酒馆等级并奖励稀有魔法物品。

---

### 七、魔法物品（宝物）

宝物是全局被动效果，与 SRD 中经典魔法物品呼应，但使用原创名称以避免直接复制。

| 宝物名称 | 效果 |
|----------|------|
| 再生护符 | 每回合结束时，恢复英雄 2 点生命值。 |
| 速度之靴 | 你的冒险者攻击时，有 10% 几率先攻（连续攻击两次）。 |
| 力场戒指 | 每场战斗一次：给你的一个冒险者施加力场护盾。 |
| 火球魔杖 | 战斗开始时，对 3 个随机敌人各造成 1 点伤害。 |
| 亡灵法书 | 你的亡者遗赠效果额外触发一次。 |
| 巨人力量腰带 | 你的冒险者获得 +1 攻击力。 |
| 移位斗篷 | 你的冒险者有 15% 几率闪避攻击。 |

玩家最多携带 6 件宝物，可通过精英、Boss、商店或事件获得。

---

### 八、事件（奇遇）

事件系统沿用 JSON 数据驱动，从 SRD 地城遭遇中获取灵感。

示例事件：
- **魔法喷泉**：饮用泉水 → 恢复 5 生命 / 获得一个随机 2 星冒险者 / 投一枚硬币（随机正负效果）。
- **贪婪的宝箱怪**：战斗或逃跑 → 胜利获得大量铸币，失败则全员受到 1 点伤害。
- **幽灵的恳求**：帮助幽灵 → 失去一件宝物，获得一个强力冒险者；无视 → 无事发生。

所有事件选项的后果都会清晰显示，玩家做出选择后立即执行。

---

### 九、局外成长

增加重玩性和目标感，使用本地存档（JSON）。

- **职业解锁**：用初始战士通关后解锁游荡者，依此类推。
- **进阶地城**：通关后解锁“困难模式”，敌人 +2 攻击/+2 生命。最高 5 阶。
- **冒险日志**：记录最佳通关阵容、最高伤害、最爱种族等。

### 十、技术架构

#### 10.1 目录结构
```
tavern_rogue/
├── main.py
├── game/
│   ├── engine.py          # 战斗模拟器（事件队列）
│   ├── recruit.py         # 酒馆招募界面与逻辑
│   ├── hero.py            # 英雄职业与状态
│   ├── map_manager.py     # 地图生成与路径选择
│   ├── node_handler.py    # 节点事件分发
│   ├── rewards.py         # 战利品生成与选择
│   ├── relics.py          # 宝物管理
│   └── events.py          # 随机事件解析
├── data/
│   ├── adventurers.json   # 冒险者数据
│   ├── relics.json        # 宝物数据
│   ├── enemies.json       # 怪物配置
│   ├── events.json        # 事件表
│   └── map_templates.json # 地图模板
└── ui/                    # 命令行界面（可后续替换）
```

#### 10.2 战斗引擎关键点
- 所有效果由 `adventurers.json` 中的 `script` 字段定义，引擎只负责解析并生成事件。
- 事件队列使用 `collections.deque`，后进先出处理。
- 属性修改器（如宝物加成）动态计算，不写死基础值。
- 完整战斗日志，便于调试和展示。

#### 10.3 数据驱动示例
```json
{
  "id": "dwarf_defender",
  "name": "矮人防御者",
  "tribe": "dwarf",
  "tier": 2,
  "attack": 2,
  "health": 4,
  "keywords": ["GUARD"],
  "script": {}
}
```

### 十一、开发路线图（2.0 版）

**第一阶段：核心战斗与招募（3 周）**
- 实现 `engine.py`：支持守卫、力场护盾、亡者遗赠、连击。
- 编写 15 个 1-2 星冒险者数据，含 SRD 种族。
- 命令行招募界面：买怪、卖怪、三连、站位调整。
- 单元测试覆盖各种关键词互动。

**第二阶段：地图与节点（2 周）**
- 地图生成器，固定模板 + 随机填充。
- 怪物加载与战斗奖励。
- 主循环：招募 → 选节点 → 事件处理 → 下一层。

**第三阶段：宝物与事件（2 周）**
- 宝物系统及触发时机（战斗开始、购买时、亡语等）。
- 事件系统，可解析 JSON 选项。
- 英雄职业及其技能实现。

**第四阶段：内容填充与平衡（2 周）**
- 制作至少 30 种冒险者（1-6 星），5 个 Boss 配置。
- 平衡性调整，测试多种流派（矮人守卫流、精灵闪避流等）。
- 增加局外成长和解锁逻辑。

**第五阶段：打磨与可玩版本（1 周）**
- 完善命令行 UI，增加色彩和简易图形（可选）。
- 编写游戏内帮助文本。
- 打包为可直接运行的 Python 项目。

### 十二、法律与版权

本方案严格使用 D&D SRD 5.1 中的开放游戏内容，遵循 OGL 许可。所有名称均为 SRD 中的通用概念，文字描述、美术资源、代码实现均为原创。核心游戏玩法（自动战斗、铸币经济、三连合成）属于游戏机制，不受版权保护。因此，本项目可以作为完全独立的游戏进行发布。

**结语**

TavernRogue 2.0 是一份将热门自走棋玩法与经典奇幻规则深度融合的可行蓝图。它既保留了《酒馆战棋》极具成瘾性的阵容构筑乐趣，又通过地城冒险、宝物收集和随机事件提供了无限的重复可玩性。从命令行原型开始，你可以在数周内拥有一个完全属于自己的、可公开分享的 Roguelike 卡牌游戏。
